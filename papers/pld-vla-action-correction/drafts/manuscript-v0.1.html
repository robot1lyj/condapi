工作标题 · 中文初稿 v0.1 · 2026-10-13

写作定位。 整篇论文围绕 VLA 的局部动作修正与持续学习展开。本版先完成第一部分：RTC 与残差 RL 的执行衔接。RTC 及实时 VLA 强化学习已有先例；本文的小亮点落在具体的执行、交还与学习接口。后续 RL 结果及架构研究将补充论文的核心贡献。方法以实现快照 22fcebf 为依据；部署测量对应其中归档的 e21431b 版本。方括号标记需要实验填入的结果。

摘要

视觉—语言—动作模型为机器人提供了完整任务的行为先验，局部强化学习则提供了从现场经验中改进动作的途径。将两者接入持续执行系统，需要同时处理动作的执行承诺和学习反馈：新观测到达时，先前生成的修正可能仍在队列中，结果判定也可能晚于停止新增修正的时刻。我们构建一个以冻结 VLA 为底座的局部残差学习框架，在保留 RTC 执行节奏的同时，用有界动作编辑、排队完成后的结果结算和来源核验连接决策与经验。框架分别计算正负方向的可行修正空间，并在强制等待阶段继续传播价值、关闭新增动作与策略熵更新。在已归档的系统核验中，真实零残差 rollout 的 116 个诊断区间均完成动作来源核验；集成 actor 的 Thor 本地录像输入测试中，48 个模式用例均保持已承诺前缀，活动 actor 用例服务时延 P95 为 223.91 ms。上述结果建立了 RTC 与残差学习的执行接口。后续实验将沿固定交互预算下的局部成功、完整任务收益及专家经验回灌三个层次检验框架。

1. 引言

VLA 把语言目标、视觉场景和机器人动作连接起来，使同一模型能够承担完整操作流程。真实部署进一步提出了一个学习问题：当底座已能完成大部分动作，而失败集中在接触、抓取或交接等局部过程时，如何把现场尝试转化成可重复的动作改进？冻结底座并训练小型专家，提供了利用已有能力、集中交互预算的路径。PLD 将专家学习、部署分布上的数据采集和 VLA 微调组织为一个闭环，为这一方向提供了直接基础。[1]

持续执行使这个闭环具有明确的时序结构。VLA 生成动作块的同时，控制器继续消费已有队列；下一次观测对应的物理变化，可能来自更早的请求。局部专家停止输出时，已承诺的修正也可能继续执行。因而，动作编辑、控制交还和结果结算需要共同描述一次尝试，才能把现场记录转换成一致的学习样本。

已有实时 VLA 强化学习将最新观测编辑、延迟观测与前缀条件纳入学习过程。[2] 我们沿这一方向，研究局部专家在 RTC 队列中的完整生命周期：从可编辑后缀生成修正，经过已承诺动作的执行，再以对应结果结束局部经验。本文第一部分将这一过程具体化为三个接口：保留零修正语义的有界动作空间、区分停止生成与排队完成的交还状态机，以及按原生观测区间重建的 replay。

这一设计的直接价值是让 VLA 的连续执行与局部学习共享同一套动作语义。底座负责长程行为，专家在局部窗口内修正六个关节和夹爪；视觉结果在控制路径之外评定，并沿原始尝试标识返回学习系统。以 YAM 双臂抓取为实例，本版给出方法、实现核验和用于后续策略实验的评价协议。后续研究将进一步确定残差表示、价值学习和专家经验回灌的组合，形成完整论文的贡献链。

2. 相关工作与研究位置

从行为先验到局部专家。 残差强化学习把已有控制器与可学习修正组合起来。[3] PLD 用冻结 VLA、残差专家和分布对齐采集支持后续微调；PARTS 将长程任务中的局部子任务组织成自主实践与交还过程。[1,4] 本文采用这条总体路线，并研究持续执行条件下的具体学习接口。

实时动作编辑与策略表示。 Real-Time EXPO-FT 已将 RTC 前缀与实时编辑结合，是本文时序设计的直接比较对象。[2] RLT 则利用 VLA 表征与参考动作构造小型 RL 策略。[5] 两者分别启发执行接口和专家输入设计。本文当前实现使用冻结视觉编码、底座计划和执行状态；后续表示研究将保持相同的执行与奖励接口，以比较信息表达带来的学习收益。

局部结果与下游任务。 局部持物成功为抓取提供清晰的学习反馈，而抓姿也会影响后续运输和放置。Foresight Residual RL 已研究这种下游交接价值。[6] 本文分别评价局部结果和完整任务结果，并将交接质量作为可比较的扩展。PLD 式 SFT 与 RECAP 式后训练提供了不同的经验吸收路径；当前以专家学习为起点，为后续回灌保留数据接口。[1,7]

3. 框架：长程底座与局部学习

冻结 VLA 根据多视角图像、本体状态和任务指令生成参考计划。入口模块读取当前状态与该计划的可编辑后缀，选择局部修正窗口及活动臂。残差策略输出一组七维参数，确定性解码器将其映射成满足命令约束的短时修正。控制器沿原 RTC 调度执行，记录观测、请求身份、计划索引和实际下发命令。

离线处理将执行记录关联到局部尝试，结合运动学与视觉证据发布结果奖励。Actor–critic 按批次更新，生成带有模型和动作合同版本的专家快照，供后续 rollout 使用。评分与训练分处执行路径之外，结果可以在一次 rollout 完成后统一回填。

图 1. 整体架构。 上层负责连续执行，下层将实际经验转成局部学习信号。末端回灌为后续研究模块。框架接口可用于不同局部目标；具体入口和结果谓词由任务适配器提供。

4. 第一部分：RTC 中的残差执行与经验对齐

4.1 在可编辑后缀内生成修正

令第 i 次原生观测对应的参考计划为 Bᵢ ∈ ℝᴴˣᴰ，已承诺前缀长度为 dᵢ。当前实例使用 H=50、D=14，排列为左臂六关节、左夹爪、右臂六关节、右夹爪。每次决策选择一只活动臂，以共享策略修正其七个维度；另一臂沿底座计划执行。

策略输入 xᵢ 包括三路图像的冻结 ResNet18 特征、本体状态、参考计划、上一实发命令、活动臂、RTC 延迟、窗口阶段和可行幅度。当前输入为 2,287 维。策略在归一化空间产生 uᵢ=tanh vᵢ ∈ [-1,1]⁷，分别按正负可行比例 sᵢ⁺,sᵢ⁻ 映射：

aᵢⱼ = uᵢⱼ × { s⁺ᵢⱼ 当 uᵢⱼ ≥ 0；s⁻ᵢⱼ 当 uᵢⱼ < 0 }
公式 1 · 查看 LaTeX
a_{ij}=u_{ij}\begin{cases}s^+_{ij},&u_{ij}\geq 0,\\s^-_{ij},&u_{ij}<0.\end{cases}
\tag{1}

令 ρ 为各维物理修正半径、Mᵢ 为活动臂选择矩阵，物理命令计划为

Aᵢ[k] = Bᵢ[k] + wᵢ[k] Mᵢ (ρ ⊙ aᵢ)
公式 2 · 查看 LaTeX
A_i[k]=B_i[k]+w_i[k]M_i(\rho\odot a_i).
\tag{2}

其中 wᵢ 在前缀和编辑窗口外为零，在 dᵢ 开始的八个 tick 上依次取 [0,1/3,2/3,1,1,2/3,1/3,0]。这使修正渐入渐出，并在边界回到底座计划。八个 tick 描述包络长度；请求与实际消费仍沿原 RTC 调度。

正负可行比例由计划各位置的关节/夹爪上下限、相邻命令变化及残差增量共同确定。方向分离保留了端点处的有效动作：例如夹爪位于开度上限时，闭合方向依然可以具有非零修正空间。对全部输入，uᵢ=0 对应经过同一 SDK 映射的物理底座计划，因而零修正具有明确的执行参照。

当前抓取实例的候选半径为关节 0.02 rad、夹爪归一化开度 0.05，再由上述比例收缩。网络前缀逐值保留；物理命令与网络命令通过已声明的 SDK 夹爪映射对应。约束覆盖命令范围与连续性，机器人接触保护继续由原控制系统承担。

4.2 把停止生成、排队完成和结果结算分开

局部窗口包含 correcting 与 draining 两个在线阶段，并在取得结果证据后完成结算。

在 correcting 阶段，专家对可编辑后缀提出修正。达到局部退出条件后，系统进入 draining，将新增残差置零，同时保留已经承诺的前缀。机器人继续执行队列。系统记录此前提出的残差包络的最晚可能结束 tick，并在该时刻之后保留至少两个控制 tick 的观测余量，再完成窗口。

时间 →        生成修正          停止新增          残差尾部完成       结果结算
专家输出      有界残差          零新增残差        零新增残差
实际执行      旧队列＋新修正    已承诺修正继续    Pi 继续执行
学习记录      决策转移          等待转移          新鲜结果证据 → 终止奖励

图 2. 控制交还的三个时刻。 停止生成新修正后，学习窗口覆盖已承诺的残差尾部。等待过程中 Pi 继续运行，无需安排固定一秒的静止保持。队列尾部由在线计划给出保守时刻，实际消费由离线执行记录核验。

抓取实例以已观测接近过程中的最低 FK 高度为相对参考。首次有效累计抬升达到 5 cm 时停止新增修正；重新张开及预先定义的任务时间预算也可触发退出。在线高度门槛负责时序管理，持物结果由后续视觉证据确认。预计抓取后 2 s 无实际闭合、闭合后 3 s 未退出，是当前实例的预算参数。

4.3 按实际观测区间重建经验

每条 replay 转移对应相邻原生观测之间的真实区间 [tᵢ,tᵢ₊₁)。处理器逐 tick 核对请求 token、原计划索引和实际下发命令，使跨越新观测继续执行的前缀保持原始来源。参考计划、策略样本、物理解码命令和实际消费记录共同绑定到动作合同。

这一设计保留延迟动作的学习链条：某次残差在下一观测区间执行时，其效果仍能沿队列状态与后续转移传播回来。critic 的动作输入是式 (1) 的七维残差参数，状态包含参考计划与队列信息；实发命令用于验证该转移的执行语义。每次尝试按连续区间编译，人工接管、取消、记录缺口和未知命令改写按原因记录并隔离。

4.4 用可观察的局部结果闭合奖励

奖励绑定到一次局部尝试，在最后一个核验区间发放一次；中间区间奖励为零。当前抓取目标定义为抓起并保持住：held 给 1；empty、not_lifted、no_closure、dropped 给 0，并保留具体原因。

结果类型决定证据要求。held 和 empty 使用队列尾部完成后、满足相对抬升条件的图像；成功审核需要两个不同视频帧，并包括最后可用帧。未抬升和未闭合使用完整实测轨迹、终态新鲜图像及抓取意图复核；掉落使用先持物、后丢失的时序证据。因此，失败监督覆盖了到达抬升门槛之前的失败。数据缺失、设备故障和误入口单独记录，评价同时报告这部分覆盖情况。

首轮结果由 Qwen 序列判断与 DINO 参考辅助审核，发布后冻结奖励版本。SAM/DINO 的历史抓取区间标注用于证据整理与规则开发。新鲜性依据相机接收记录和视频索引。标签计算或人工审核的返回时刻与物理事件时刻分别保存，训练奖励关联到原尝试终点。

5. 第二部分：以执行一致的经验训练局部专家

5.1 当前 SAC 学习接口

定义 cᵢ ∈ {0,1} 表示当前状态具有可用的残差控制空间。排队阶段令 sᵢ⁺=sᵢ⁻=0，因此 cᵢ=0。以真实经过时间 Δtᵢ 折扣，当前实例采用每秒折扣 γₛ=0.99。双 critic 的目标写为

yᵢ = rᵢ + (1 − dᵢᵗᵉʳᵐ) γₛ^Δtᵢ × [ minⱼ Q̄ⱼ(xᵢ₊₁, a′ᵢ₊₁) − α cᵢ₊₁ log πθ(u′ᵢ₊₁ | xᵢ₊₁) ]
公式 3 · 查看 LaTeX
y_i=r_i+(1-d_i^{\mathrm{term}})\gamma_s^{\Delta t_i}
\left[\min_{j=1,2}\bar Q_j(x_{i+1},a'_{i+1})
-\alpha c_{i+1}\log\pi_\theta(u'_{i+1}\mid x_{i+1})\right].
\tag{3}

dᵢᵗᵉʳᵐ 表示局部尝试的已核验终止，与前缀长度 dᵢ 区分。a′ᵢ₊₁ 通过同一方向可行映射生成。强制等待时 a'=0，critic 继续学习等待后的结果，actor 与温度在该状态上跳过更新。可控制状态上的 actor 目标为

Lπ = E[xᵢ : cᵢ = 1, uᵢ ∼ πθ] [ α log πθ(uᵢ | xᵢ) − minⱼ Qⱼ(xᵢ, aᵢ) ]
公式 4 · 查看 LaTeX
\mathcal L_\pi=\mathbb E_{x_i:c_i=1,u_i\sim\pi_\theta}
\left[\alpha\log\pi_\theta(u_i\mid x_i)-\min_jQ_j(x_i,a_i)\right].
\tag{4}

这里的熵定义在 tanh 后的策略采样变量 u 上。状态相关的可行映射负责物理动作解码。式 (3)–(4) 采用 SAC 的基础更新，并将实际时间和强制等待状态纳入当前执行接口。[8]

5.2 从底座经验到修正经验

历史 14 集自主底座数据形成奖励开发集和零残差行为参照。当前审计中，327 个合格标签对应 136 个持物和 191 个空手结果，其中 311 次尝试形成 31,077 条历史转移。E02–E14 的 299 次尝试用于训练诊断，E01 的 12 次尝试用于开发验证；E01 参与了规则开发。新合同的学习数据来自携带完整参考计划、残差样本及执行来源的 rollout。

专家以零均值初始化，在采集模式进行有界探索，在评价模式使用确定性输出。每轮先核验真实执行与结果，再更新策略。PLD 的价值初始化和混合 replay 为后续数据利用提供比较方向；当前动作块 SAC 基线与历史单 tick 离线诊断分别管理，Cal-QL 初始化作为独立的后续比较因素。[1,9]

5.3 后续架构研究的接口

后续设计围绕三个可分别检验的问题展开。第一，何种视觉、VLA 或队列表征最有利于判断修正方向？第二，固定残差包络与更灵活的动作表示如何影响交互效率和交还质量？第三，局部结果与下游任务价值如何共同指导专家，使抓取改进转化成完整任务收益？

每项比较复用相同底座、入口、执行合同及奖励版本，并明确更改的模块。确定有效专家后，再以部署分布上的采集和原生微调研究能力回灌。这样，RTC 接口为算法比较提供稳定基础，后续架构贡献由学习结果与机制实验形成。

6. 结果与实验设计

6.1 动作来源与前缀保持

在一集真实零残差 probe 中，记录包含 320 个完整回复和 3,347 个底座策略 tick；用于诊断的 116 个区间全部完成来源核验。其间 12 个区间包含已声明的 SDK 夹爪端点转换。以同一物理映射定义底座后，这些区间保留了完整的动作解释。[S1]

在修订后的集成服务上，48 个真实录像输入的模式用例覆盖左右臂、四种模式及三次重复，全部满足前缀逐值保持和物理解码一致。原客户端校验器另对 16 个真实返回包通过校验。排队状态前向检查同时满足零新增残差、前缀保持和队列完成条件。[S2] 这些测量说明，局部编辑可以沿已有 RTC 协议传递，并保留其执行身份。

6.2 推理开销与学习闭环

7. 讨论

连续执行给局部学习带来的关键变化，是动作生成、动作完成和结果可见具有不同的时间边界。本文第一部分把这些边界显式连接起来：可编辑后缀定义当前选择空间，排队阶段保留先前承诺，原生记录将结果关联到对应的局部经验。这为不同 RL 算法和专家架构提供了可比较的执行基础。

通用性可以分层验证。执行来源、队列管理和更新接口可在任务之间复用；局部入口和结果证据则表达任务语义。后续跨任务研究将同时衡量策略表现与适配成本，以区分接口复用、少样本适配和零样本迁移。长期能力则通过关闭专家后的 VLA 评价来检验，使专家系统的现场收益与底座自身的能力变化各有对应证据。

8. 结论

本文建立了持续执行 VLA 与局部残差学习之间的接口：在可编辑动作空间中修正，在已承诺队列完成后结算，并沿真实执行来源形成经验。RTC 与 RL 的衔接构成论文的第一部分，为后续策略学习、架构比较和经验回灌提供一致基础。整篇工作的目标，是把局部尝试积累为可重复的动作能力，并进一步沉淀到 VLA。
