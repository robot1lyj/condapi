# 候选论证地图

2026-10-13：论文按三层推进。第一部分为 RTC 与残差 RL 的执行衔接，作为具体机制的小亮点；第二部分给出局部学习与完整任务收益；第三部分由后续架构、跨任务及经验回灌实验形成。RTC 与实时 VLA RL 均引用已有先例，核心贡献随结果确定。

## 已知与张力

冻结 VLA 并以残差 RL 修正局部动作已被多篇工作验证。真正的难点不再是“能否外挂小专家”，而是在连续真机轨迹中，反馈何时可信、动作何时可改，以及局部改进是否转化成完整任务收益。现有项目出现过核验窗口缺少抬升证据却给出失败标签的具体反例；这提示了问题，但还不证明它是普遍瓶颈。

## 核心研究问题

在相同底座、视觉奖励器及真机交互预算下，将局部结果证据与实际可执行的残差决策对齐，是否比标准局部残差学习获得更可靠的任务改善，并减少奖励误报驱动的退化？

## 中心假设

真实长程 rollout 中，错误或过早的局部奖励与错误动作归因会削弱小专家学习；显式管理证据资格、决策边界及执行承诺，可能在多任务上改善学习效率与完整任务可靠性。该假设尚无本项目 RL 结果支持。

## 支持链

1. **先例定位**：PLD 负责专家—采集—蒸馏，PARTS 负责瓶颈实践，实时编辑与奖励 gate 也已有先例。对应 C01。结论是缩小原创范围，不是贬低这些方法。
2. **真实缺陷**：E04-L015 等审计表明结果证据可错配，现有模型一致性也不够。对应 C02。需要新鲜测试估计发生率，不能只挑反例。
3. **可测试方法**：固定编码器和 RL 算法，改变证据/执行对齐机制。对应 C04–C06。要与普通清洗及正确时间索引的强基线区分。
4. **外延检查**：跨异类任务及 expert-off 蒸馏分别对应 C07/C09；共享接口、少样本适配、零样本泛化是三个不同强度的结论。

## 实验需要区分的解释

| 反驳 | 需要的回应 |
|---|---|
| 执行接口与学习规则各贡献什么 | 分别比较正确实时基线、排队/来源机制及学习架构，按结果决定贡献层次。 |
| 多留有效数据自然会更好 | 等量有效样本比较，同时另报真实数据利用率。 |
| 更大的视觉模型才是原因 | 冻结奖励器与特征；单独做奖励模型替换消融。 |
| 局部成功与最终成功无关 | 单独报告完整任务指标、交接后成功和局部成功；引入已发表的 foresight 对照。 |
| 拒判掩盖难例 | 所有触发尝试进入任务指标分母；披露未评分及未尝试率，奖励训练过滤不改变评估分母。 |
| 多任务只是多个抓取物体 | 增加插入/释放或关合等不同完成条件；任务与本体适配成本计入。 |

## 决策

保持“PLD 式整段动作修正”的总体路线。第一部分写 RTC 与 RL 的具体执行衔接；后续用策略收益与架构机制实验继续形成主贡献。交接质量、RLT 表征和 RECAP 后训练分别按研究问题选择，并注明方法来源。当前正文见中文论文初稿，实验档案继续保存全部测量。
