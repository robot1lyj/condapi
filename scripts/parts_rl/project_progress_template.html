__QD_SVG__

DINOv3：对照“持物”和“空手”

固定裁出夹指附近的腕部画面，缩放为 256×256。冻结的 ViT-S/16 同时提取指间区域特征（ROI）和整张裁剪特征（CLS），分别与持物、空手参考图做余弦相似度比较；排除同集和同图，避免自己给自己投票。

m = 最近持物参考相似度 − 最近空手参考相似度
闭爪后 ≥0.45s 的选图：两张支持图的 ROI、CLS 差值都 >0.02 → 支持持物；全部都 <−0.02 → 支持空手；其余为混合证据。

Qwen3-VL-4B：理解前后发生了什么

最多选五张时间排序的腕部图：开始画面、闭爪后的画面、约 1.1 秒、最高点、核验末尾，重复帧去重。首图保留原腕部视野，后续放大夹指附近；输出成功／失败、置信等级、证据帧及简短理由。

提示重点：黑色三角夹指之间是否夹着前景积木；远处蓝框和散落积木属于背景；提前滑落算失败，运输后正常释放仍算成功。不能仅凭闭爪、颜色或高度判断。

两路提供互补线索，不做“模型一致就自动判成功”。当前仍结合序列复核和用户抽检；SAM3 作为历史几何基线保留，自动跟踪关闭。

把结果反馈给前面的动作
抓取结束时的 1／0 沿实际执行序列传播到此前动作，学习哪些调整更容易抓住。一次结果不重复奖励每张图；缺证据的片段不强行填 0。专家成熟后，再把有效经验蒸馏回 Pi。
执行动作 = Pi 基础动作 ＋ 有界残差 → 限位、连续性与 RTC 前缀约束 → 真实执行 → 结果奖励 → 更新专家
