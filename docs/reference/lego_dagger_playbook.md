# 乐高分拣 DAgger 方案手册

日期：2026-09-21。状态：讨论收敛后的首轮执行设计；尚未采集、实现混采、启动训练或验收 M1。

本手册是 [03 训练与评估](../03_training_and_evaluation.md) 下属操作方案；数据字段的唯一 owner 是 [04 数据合同](../04_data_contracts.md)。运行约束以 AGENTS.md 为准。本文批准的是方案记录，不构成训练、部署或操作 3588 的新授权。

## 1. 已确定路线与版本边界

- 任务：YAM 双臂乐高按颜色分拣。人工在模型运行中遥操作接管，完成当前积木的恢复与正确投放后交还模型。
- M0：固定的 20h Pi0.5 training-time RTC 任务模型；D0 为其原 941 条训练示范，2,160,813 帧、约 20.007528h。不是全量约 96h 数据。
- 每轮都从同一个 M0 原始 JAX 权重初始化，训练累计纠正数据；不继承上一轮适配权重，不每轮回官方 base。选择理由是便于追溯和比较，不宣称性能优于链式微调。
- 采集使用当前已通过验收的最好模型：M0 收 C1，M1 收 C2。M1 未通过，则继续用 M0；不能默认使用最后训练出的模型。
- 新训练保持 Pi0.5 全量微调、三相机、14D、H50、RTC 与 M0 资产合同。初始化新优化器和学习率日程；仅同一实验中断恢复使用 resume。
- 先规划三轮，每轮目标 50 次有效纠正。自动 gating、RL、残差策略及共享控制不纳入首版。

**M0 不是可变的 latest。** 截至本次本地记录，09-21 变更历史为 20h90000 下载部署流水线进行中，不是上线证据。采集前须核对真实服务 checkpoint、训练合同、配套 norm 哈希和推理配置，并写入本轮 manifest；不能将 10h80000 与 20h90000 混为同一个 M0。部署事实继续归 [RTC 手册](thor/13_trained_rtc_inference.md)。

## 2. 第一轮现场操作卡

### 2.1 先验收 5 条，再批量采集

先录 5 条完整 rollout，逐条检查三路视频、state/action 时间对应、控制权标记、接管及交还连续性、完整落盘。合格样本可计入本轮预算。接口未通过时先解决采集问题，不直接采满 50 条。

### 2.2 什么时候接管

统一人工操作规程：

1. 抓空或滑落，模型没有正确恢复。
2. 即将错投，正在朝错误颜色容器移动。
3. 同一个无效动作连续重复两次，或连续 5 秒无任务进展。
4. 明显碰撞风险立即接管，不等待上述次数。

“两次/5 秒”是工程初值，不是论文阈值；修改时记录操作规程版本。尽量在错误仍可恢复时介入，不为凑数量故意制造危险动作。

### 2.3 接管到哪里、何时交还

默认流程：模型抓空 → 人工对齐接管 → 重新抓取 → 抬起确认抓稳 → 搬运并投入正确容器 → 松开并退出接触区域 → 交还模型继续下一颗。

不要求人工完成整桌任务；第一轮也不默认在刚夹住时交还。后续若要改为抓稳抬升后交还，应作为独立采集规程记录。

接管使旧模型待执行队列和迟到请求失效；交还用最新同步观测重新规划，不接回接管前旧 chunk。以 control epoch/request ID 区分旧回复，并按实际接口处理不可撤销的已提交命令。具体平滑过渡需要采集方验收，不照搬灵巧手论文的固定 2 秒插值或物理回退。本仓库不读取、修改 3588 控制代码。

### 2.4 50 条的计数

- 50 条指 50 次经审核的连续有效纠正过程；一次长 rollout 可以有多次纠正。
- 不把一个恢复过程人为切成多条凑数。记录总 rollout 数、纠正事件数、有效专家秒数、有效 H50 起点数和失败类型。
- 自主成功、失败和无效接管全部保留原始记录；不自动当作专家训练数据。
- 不要求每段固定一分多钟；长度由完成当前恢复决定。如果实际很少出错，先做独立评估，不为了配额人为增加介入。
- 第一轮约 40 条训练、10 条验证；按原始 rollout/布局采集组分组，不能把同一 rollout 的片段分到两侧。分组导致数量不是精确 40/10 时保留隔离优先，并按实际窗口数算预算。

## 3. 数据发布与验收

格式、动作语义和拟新增字段见 [04 的 DAgger 合同](../04_data_contracts.md#dagger-纠正数据发布合同2026-09-21方案)。原始完整记录与专家训练导出分开，新版本写新目录。

发布前必须满足：

- 三相机逐帧可解码、时序和颜色正确；14D 有限且左右、单位、夹爪方向与 M0 一致。
- 专家标签确实来自审核过的人工控制，不是模型动作或下一帧反馈位置。
- 各连续片段有原始 source ID、起止时间、控制权与恢复质量标记；暂停、复位、对齐过渡与无效观测不进入专家监督。
- H50 不跨控制权边界或缺帧。首版仅选择未来 50 步都有效的起点；长度 L 帧的连续片段贡献 max(0,L-49) 个起点。
- 当前 loader 的尾部补齐不能冒充专家标签。有效窗口选择尚待实现验收；短片段保留原始库，不用重复末帧凑标签。
- 固定 train/val 清单；验证集不计算训练统计、不进入任何轮次训练。人工复位造成的场景不连续必须分段。
- 使用 M0 配套 norm 并审计新数据 transform 后范围；如发现单位错误或明显越界，先查合同。归一化迁移另开实验，不静默重算替换。

只做专家监督的首版是 HG-DAgger 风格，不是原版 IWR；整条自主经验留档，为后续方法提供可能，但本轮不引入失败动作模仿或 RL。

## 4. 第一轮实验矩阵

所有候选从同一 M0 开始，使用同一数据划分、训练代码、seed42、RTC、norm、batch 和学习率日程。比例是窗口采样比例，不是文件数量。

| 实验 | D0 | C1 train | batch32 示例 | 优先级 |
|---|---:|---:|---|---|
| M0 | — | — | 不训练 | 固定真机基线 |
| R1-A | 50% | 50% | 16 原数据＋16 纠正 | 必做基线 |
| R1-B | 25% | 75% | 8 原数据＋24 纠正 | 必做比例对照 |
| R1-C | 约 2/3 | 约 1/3 | 随机/跨 batch 调度达到目标比例 | A/B 显示旧能力退化时的可选对照 |

A/B 固定总更新数，回答“同样算力预算哪个配方好”。B 的纠正样本暴露量是 A 的 1.5 倍，这属于被比较配方的一部分；不得声称隔离了所有数据暴露因素。若 B 过拟合，可另开与 A 纠正暴露量匹配的短预算实验，但其总算力不同，单独报告。

每个池内首版按有效窗口起点均匀采样；先选择池再选择起点，避免 D0 按体量淹没 C1。记录每池实际抽样数和最长片段占比。首轮不再同时改 loss 权重、图像增强、RTC delay 或动作精度。

### 4.1 参数与预算

| 参数 | 初始设置 |
|---|---|
| 初始化 | M0 原始 JAX params；新 optimizer，step0，独立输出目录 |
| 更新范围 | 全量微调，不切 LoRA |
| global batch / 资源 | 32 / 获准服务器四卡；不在本地运行训练或训练 smoke |
| 学习率 | peak 5e-6，warmup100，cosine 至 1e-6 |
| RTC | 继承实际 M0 合同；20h准备配置为 d=0..10，不能不核对直接覆盖 |
| horizon / norm | H50 / M0 配套资产 |
| 保存 | 每1000步，并保留最终步；小于1000步时另保留中间点 |
| 初始 seed | 42；单 seed 结果不代表跨 seed 稳定 |

预算以 A 的 C1 约两遍等效起点采样制定：N1 为 C1 train 的有效起点数，S=ceil((2*N1/(32*0.5))/500)*500。A/B 使用相同 S，启动前固定 decay_steps=S。

| 假设40条连续人工片段 | N1 | A约两遍预算 | B在相同预算下 |
|---|---:|---:|---|
| 每条10秒，30Hz | 10,040 | 1,500步 | 约3.59遍 |
| 每条60秒，30Hz | 70,040 | 9,000步 | 约3.08遍 |
| 每条90秒，30Hz | 106,040 | 13,500步 | 约3.06遍 |

以真实分段和清洗结果计算，不按整个自主 rollout 时长计算。向上取整使 A 可能略超过两遍；若 N1 很小，不能因公式自动获得“已可训练”资格，先检查独立纠正事件与场景覆盖。相邻 H50 高度重叠，遍数是采样计量，不是独立信息量，不乘50。两遍、学习率均是工程初值，不是收敛保证。

如果人工片段确实约一分多钟，可预估每个实验约9k–13.5k步，A/B总共18k–27k步；最终预算在数据冻结后确定。实际GPU小时未知；旧作业约2.28秒/步只能用于排期参考，混采后需重新测量吞吐。

### 4.2 如何开始：当前缺口与实施顺序

本手册不是已可复制运行的启动脚本。当前 `scripts/train_lego_full.py` 已支持 `--init-params`、独立run、RTC、LR和resume合同，但 repo_id 仍固定单个原数据源，未接通两池混采。

顺序如下：

1. 冻结 M0 / D0 / C1 / val 及哈希，填写第7节实验卡。
2. 在既有 OpenPI loader/入口补齐 D0/C1 两池采样和有效起点过滤，不复制第二套 trainer。D0 显式限制为原941条清单。
3. 扩展训练合同：两池路径与版本、各自清单、比例、有效窗口规则、parent权重指纹、norm指纹、seed和优化器。原 subset/norm来源校验不能靠删合同或伪造provenance绕过；区分“继承M0坐标系”和“为新数据重算norm”。
4. 本地仅做轻量配置/采样/边界测试。检查实际池比例、同组split不泄漏、H50不越界、无重复delta、resume拒绝数据变化。
5. 在获准服务器上验证真实loader、有限更新、保存及重载；按 Slurm 管理训练。A/B 在同四卡资源上串行执行，避免吞吐和显存混杂。
6. 从一开始固定完整LR日程，按检查点评估。不把2k衰减完的实验直接当同一9k/13.5k计划续接。
7. 候选完成后按既有 Thor checkpoint 部署流程独立转换/精度/协议验收；未经这些验收，不进入真机比较。

## 5. 评估与上线规则

### 5.1 离线筛选

在存在的2k、5k、10k和最终点检查候选。C1验证和原验证集分别报loss，不用不同混采权重的训练总loss给A/B排名。验证保持固定采样、噪声/RTC前缀评估设置以减少波动，相关评估入口是否可用须在实施时核对。

每个实验先选一个候选；选更早checkpoint是允许的。最终比较M0、A候选、B候选，避免对所有保存点反复使用同一真机测试集。

### 5.2 真机对照：首轮60次筛查

准备20个不用于采集训练的布局模板，每个规定积木数量、颜色组合、容器位置。三个模型各测试20次，按布局分块轮换模型顺序，并重建相同初始条件；记录摆放偏差、操作者和测试日。

在独立试运行中确定整任务超时T，正式比较开始前冻结；所有候选使用相同T、控制/推理版本、去噪步数等。不能让一个模型用新的控制修复而另一个沿用旧控制。每次记录：

- 无接管整任务成功/失败；需急停或接管即自主失败，剩余测试可终止。
- 抓空、滑落、错投和异常控制事件数。
- 成功任务完成时间，以及所有尝试含超时的耗时；不把失败删除后只报告速度。

训练采集轮的接管率因难例组成变化不能直接当A/B胜负。若另测人工负担，固定独立的受监督测试布局与接管规程，分别报告次数、专家秒数和总任务时间。

### 5.3 选择与小范围部署

先排除未通过推理验收或出现新增异常跳变/碰撞问题的候选。以自主成功数为主，失败类型和耗时为辅。

首轮每模型20次只能筛查：领先M0至少3次是进入新一批复核的工程触发值，不是统计显著性门槛。A/B相差不足3次时也不宣称谁更好，可保留A基线或扩样。对最终候选与M0再各做20次新的匹配布局，报告两批及累计结果；改善方向保持且无新控制退化，才进入下一轮受监督采集。无清晰改善则保留M0。

报告成功数/总数与Wilson 95%区间；小样本区间较宽，不将3/20差异或区间判断当作严格配对显著性检验。两批独立候选测试均>=18/20可触发更长时段验证，不等于生产可靠性认证。训练继续降低loss但现场无收益时，先查标签、相机/控制时序和过拟合。

## 6. 后续轮次

固定M0初始化，聚合所有合格历史纠正；以前各轮验证集永久隔离。第二轮的数据是D0+C1+C2，第三轮是D0+C1+C2+C3。

此前讨论的D0/历史/本轮=50/25/25保留为候选，不是已确定的最优比例。根据第一轮选定D0保留量，再决定历史纠正与本轮分配。High-DoF论文的50%新+50%历史不等于该三池比例。

固定M0并未学过任何C，因此历史C属于本轮必须重新学习的内容，不仅是防遗忘回放。预算逐池记录E_j=S*B*p_j/N_j，检查历史与新纠正均有足够暴露；不能简单把第一轮S照搬，也不能只按最新C计算。任何配比变更建立新实验合同。

连续两轮没有清晰收益，暂停机械扩量，按失败类别复核数据和执行系统。先用最新合格模型收集剩余错误，不默认每轮都扩大到100/200条。RL和自动介入需要另案设计。

## 8. 参考论文与证据边界

查阅日期2026-09-21。以下将作者采用的配方与比例消融分开；所有机器人/LLM结果均不是YAM样本量或步数保证。

| 文献 | 重点及已核对结论 | 本方案采用与不采用 |
|---|---|---|
| [Towards High-DoF Dexterous Manipulation through VLA Post-Training, 2026](https://arxiv.org/html/2609.19666v1) §4.3、B.2 | SFT→每轮50纠正→残差RL；每轮从同一官方Pi0.5初始化30k步，50%新纠正/50%累计历史 | 借鉴分轮聚合与过采样；未复现其初始化、54D灵巧手、物理回退、RL；没有证明该比例最优 |
| [Hand-in-the-Loop, 2026](https://arxiv.org/html/2605.15157v2) §3、4.4 | 相对手部映射、手臂速度共享控制及完整接管；20h基础模型+1h新增，新:旧采样0.5:1，即1/3:2/3 | 支持任务模型继续适配与接管连续性；没有证明多轮链式优于固定M0，也未证明混采比例最优 |
| [Human-in-the-Loop Imitation Learning using Remote Teleoperation / IWR, 2020](https://arxiv.org/html/2012.06733v1) §IV-C、V | 人工介入/机器人自主样本等量采样，对比非平衡IWR-NB；实验为仿真任务 | 借鉴纠正加权；本方案D0是专家数据，不等同原版IWR的自主池 |
| [ThriftyDAgger, 2021](https://arxiv.org/html/2109.08273v1) | 新颖度、风险与人工预算驱动介入 | 首版由人判断，不引入额外gating模型 |
| [AIM, ICML 2025](https://metadriverse.github.io/aim/) | proxy Q自适应介入，主要实验MetaDrive/MiniGrid | 自动gating后置，不移植其阈值作为YAM已验证指标 |
| [RLIF, ICLR 2024](https://arxiv.org/html/2311.12996v2) Algorithm2 | 介入发生时对前一transition赋-1，否则0，以off-policy RL利用信号 | 保留事件以便将来研究；当前不训练RL |
| [Original DAgger, 2011](https://proceedings.mlr.press/v15/ross11a.html) Algorithm3.1 | 当前策略访问状态的专家标注与累计数据训练，处理分布偏移 | 聚合历史纠正；不要求某一种现代神经网络checkpoint初始化 |
