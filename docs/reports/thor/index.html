  • 回放路径 · Thor 本地离线

    数据位于 /home/wuyan-lyj/thor/pi/test-data，容器只读挂载 /test-data；服务器只作为一次性下载来源，推理计时不含服务器网络传输。下一步准备固定输入及匹配的 benchmark-only YAM norm_stats。

  • 测试工具 · 11 项单元测试通过

    覆盖权重 dtype 选择、本地输入校验和中文 HTML 展示；尚未执行模型推理，不用单元测试替代真实 GPU 结果。
