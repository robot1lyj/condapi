# PLD 多算法离线对照：14 集固定数据

2026-10-12 用户授权继续并行实验，以 `pld-<论文方法>-<设置>-s<种子>` 命名。PLD 表示冻结 Pi + 小残差专家框架，后缀表示学习目标。这里是核心算法的 YAM 适配，不是原论文硬件、数据及完整线上实验的逐项复现。

## 配方

| 方案 | 数量 | 核心更新 | 设置 |
| --- | ---: | --- | --- |
| PLD-IQL | 4 | expectile V、数据内 Q、优势加权高斯策略似然 | expectile 0.7 / 0.9，各 seed 0/1；温度 3，权重上限 100 |
| PLD-TD3BC | 2 | 双 Q、目标动作平滑、Q 最大化 + 行为约束 | seed 0/1；α=2.5，BC 按动作维平均，策略每 2 步更新 |
| PLD-ReBRAC | 4 | next-action 行为惩罚进入 backup、actor 行为约束、critic LayerNorm | seed 0/1；actor β=1，critic β=1 / 0.01；策略每 2 步更新 |

共用 E02–E14 的 299 次抓取 / 29,842 条转移训练，E01 的 12 次抓取 / 1,235 条转移作开发验证。成功和空抓均保留，不加额外成功示范。数据版本 `pld-offline14-20261012-v2`、奖励、图像引用、冻结 ResNet18 缓存不变；先均匀抽尝试，再均匀抽尝试内转移。

每组 20,000 更新、batch 256、Adam 3e-4、FP32、TF32 关闭、τ=0.005、梯度裁剪 10，每 100 步记录、500 步验证、5,000 步保存。主比较八组四卡分两波，后续两组低critic惩罚对照使用两卡，每卡一组。IQL/TD3BC 为 2×256 ReLU，ReBRAC 为 3×256 ReLU + critic LayerNorm，因此不是只改变单一 loss 的消融。统一预算没有照抄 ReBRAC 的 1e-3 / batch 1024 / 百万步，也没有采用 IQL 的 cosine actor 衰减。

残差均值 `u=tanh(actor(x))`，Q 接收 `Pi_base + 0.25 × action_std × u`。std 只由 E02–E14 拟合，不转换原单位；这只是离线动作参数化，**不是已批准的物理部署限位**。活动臂输出 7D，左右共享网络。Pi / 视觉冻结；actor 零头初始化，不做单独 BC 预热。

IQL 使用状态无关对角高斯，均值 tanh，log std 裁在 [-5,2]，与作者公开配置的策略形式一致；诊断只用均值，不下发高斯样本。TD3 系方法在 u 空间加 σ=0.2、clip=0.5 的目标平滑噪声，再裁到 [-1,1]。实际时间折扣、按尝试抽样、残差坐标、零头初始化与冻结视觉是项目适配。

## 奖励与限制

抓取检查终点对应转移给持物 1 / 空手 0，中间 0，terminal 不 bootstrap，不复制奖励到每帧。整轮 C/N 只归档，不任意与局部奖励相加。数据全部是零修正行为；IQL 均值应保持零，不能称学会修正。TD3BC/ReBRAC 的非零偏移可能是 Q 外推误差，没有实际动作结果时，critic 自评增益不能证明成功率提升。

这些 run 是单 tick 离线学习，不代表整段动作/RTC 已完成。在线入口、物理投影、承诺前缀、连续性及取消语义尚未验收；本次不改 Thor 或客户端。

## 评价与归档

固定最后一步为主要对照，`best-diagnostic.pt` 仅便于分析。E01 已用于多轮调试，不是独立测试集，只有两次失败；左臂没有失败，AUC 无定义。

- 数值：Bellman 误差、Q 范围、双 Q 分歧、末步奖励 RMSE、梯度、有限值。
- 回报：逐尝试入口 MC RMSE / AUC、训练均值常数及常数 1。优化策略 Q 与实测行为回报不同，不能单凭 MC RMSE 判策略优劣。
- 动作：残差 RMS、边界饱和比例、左右臂预测；自评 gain 不是实测收益。
- 来源：实际更新次数、参数量、GPU 显存、更新/加载时间、配置/代码/数据 SHA、环境及 Slurm 号。

服务器新目录 `runs/pld-methods14-20261012-v1/` 与 `runs/pld-methods14-20261012-v2/` 保留配置、原始 metrics、每次验证的 311 次尝试预测、优化器/RNG/目标网络检查点及失败日志。原八组 critic-only 原件和 ID 不变，仅补统一展示名；复用 8766 看板。作业与汇总已完成，结果见下。

## 来源

- [PLD](https://arxiv.org/html/2511.00091v1)：冻结 VLA、残差专家、后续在线 RL / 蒸馏的主框架，本轮没有完成其线上 SAC。
- [IQL 论文](https://arxiv.org/abs/2110.06169)、[作者代码](https://github.com/ikostrikov/implicit_q_learning)：expectile、数据内 Q、优势加权策略。
- [TD3+BC 论文](https://arxiv.org/abs/2106.06860)、[作者代码](https://github.com/sfujim/TD3_BC)：目标平滑、延迟更新、归一化 Q / BC。
- [ReBRAC 论文](https://arxiv.org/abs/2305.09836)、[作者 CORL 实现](https://github.com/tinkoff-ai/CORL/blob/main/algorithms/offline/rebrac.py)：next-action 惩罚在 backup 内，actor 使用 min 双 Q 和动作维求和 BC。

按来源公式独立实现；审读代码 URL、访问日期、内容 SHA 归 [paper-sources.json](paper-sources.json)。原 ReBRAC raw 路径不可取，使用作者 CORL 版本并记录替代来源。

低惩罚两组是看到首波 ReBRAC 负值后设计的后续诊断，不能作为预注册独立结果。原 ReBRAC 的目标平滑噪声也参与 next-action 惩罚；在本项目接近 1 的逐tick折扣下，重复惩罚可能主导稀疏奖励。只把 critic β 从 1 改为 0.01，不改变奖励、折扣或 actor β；保留原结果，不把负 Q 直接称为数值爆炸。

## 实际结果

Slurm 2313（四卡，3分52秒）与 2314（两卡，1分36秒）均 COMPLETED / 0:0，10/10 组完成 20,000 次 Q 更新。IQL 每组 actor 更新 20,000 次，TD3BC/ReBRAC 每组 10,000 次。Pi、视觉及机器人未更新/运行。单组更新阶段 72.1–112.3 秒；本次复用已有图像缓存，不包含重新提特征。网络可训练参数分别约 191万 / 143万 / 163万。

| 方案 | E01 入口行为 MC 对照 RMSE，两个种子 | E01 入口 AUC，两个种子 | 验证转移上残差 u RMS |
| --- | --- | --- | --- |
| PLD-IQL / e0.7 | 0.835 / 0.802 | 0.50 / 0.45 | 0 / 0 |
| PLD-IQL / e0.9 | 0.674 / 0.685 | 0.50 / 0.45 | 0 / 0 |
| PLD-TD3BC | 0.860 / 0.736 | 0.10 / 0.10 | 0.205 / 0.177 |
| PLD-ReBRAC / critic β=1 | 15.535 / 15.890 | 0.50 / 0.85 | 0.0036 / 0.0039 |
| PLD-ReBRAC / critic β=0.01 | 1.671 / 1.512 | 0.45 / 0.70 | 0.0159 / 0.0115 |

训练均值常数的行为回报 RMSE 为 0.556，常数 1 为 0.410。没有一个方案在这个行为回报诊断上超越这些基线；但本轮 Q 的优化目标与行为 MC 并不完全相同，表格也不能当策略成功率排行榜。只有 12 次验证、两次失败，种子差异显著，需要新独立真机评估。

IQL 在零残差数据上保持 actor 均值为零，是参数化和训练目标的预期结果，不是修正能力证据。TD3BC 输出非零偏移，但两种子入口 AUC 均为 0.10，没有可信的改善证据。ReBRAC 降低 critic β 后，入口误差和负值尺度明显减小，支持惩罚权重敏感的解释；仍没有通过真实策略验证，不能把这个观察归因为唯一原因或称已解决。

**本轮完成离线方法比较，尚无可直接上线的修正专家。** 后续应先补有实际执行结果的非零有界修正经验、形成因果入口与 RTC/物理动作合同；不能靠复制旧数据或继续增加更新步数声称获得修正能力。在线配方与客户端需求另行形成可审核提案。

两次 GPU 数值检查全部通过，保存预测重算 10/10 AUC 一致，入口 RMSE 最大差 6.4e-8；8766 API 18/18 个 run 可读、无坏行，新增各 20,000 步、旧组各 5,000 步。新增 50 个 checkpoint、400 个逐尝试预测文件已保留服务器；runs/index 与 source/index 登记数据/代码/比较 SHA，未覆盖原八组。
