## 可解释的候选规则与限制

测量夹爪开度使用开/闭迟滞找候选；遇到 tick/epoch 或时间断裂即切断。每0.20秒及进入/闭爪/结束关键行取腕部图像；视频按记录的 `video_indices` 对齐，不能把控制行号当视频帧号。相机时间来自 `camera_host_received_at`，不是已经验证的硬件曝光时间；本批该字段没有非有限值。

最终相对高度使用**候选进入行**的各臂 base-Z，不使用未来最低点。初始提取曾保存闭爪附近最低点；原 `candidates-unscored.json` 与提取脚本快照保留，最终文件中的 `earlier_provisional_reference` 只作溯源，不参与最终建议。进入点只是闭爪启发式的进入行，仍需验证是否对应正式 selector；向上轴尚未标定。所有高度结果均为候选证据。

SAM3 使用 `LEGO brick`、`plastic storage bin`、`robot gripper fingers` 三个文本提示。结合指间图像区域、容器排除、分割面积/位置连续性、夹爪状态、新鲜且不同的帧，建议成功需相对进入行抬升≥5cm、连续持物≥1秒。零检测、模糊、遮挡或快速放置均不足以判失败。空手负例还要求明确的夹爪正检和连续空隙证据；当前提示词在这些 YAM 夹爪图像上识别不足，不能为了得到负例降低门槛。失败尝试会因此留在不确定项中等待审核。

这些规则不是已验证的奖励模型，没有人工 precision/recall 或在线验收；遮挡、白色积木、容器边缘及桌上积木可能误检。人工审核还需检查候选边界与参考点，不能只核对叠图是否分割到了积木。审核结果不能补出尚未执行过的专家残差。

**主要数据问题是把“这一行观测不可用”当成了“整个抓取尝试结束”。** 全273个候选有126个以`trace_gap`结束；只读H5确认126处全部`observation_valid=false`，相机接收时间三路都为0，但`measured_state__valid=true`、对应臂`pose_valid=true`、tick相邻、epoch不变，机器人仍在policy阶段。这里只能确认记录行没有可用相机观测，不推断相机硬件断联的原因。

在63个无图候选中，55个受上述截断影响：51个仅缺1行，另4个缺2–4行，下一有效行与最后有效行间隔最大0.1715秒。保持原进入高度、原开度门槛，并在密集轨迹中仅诊断延续同epoch/tick、有效FK的同一闭合窗口，**48个旧候选在截断后出现了满足原闭爪+5cm条件的有效行**。这意味着有后续画面值得重提取，不是新增48个成功，也不是48个独立抓取；窗口可能重叠，重建attempt时必须去重。没有跨无效行伪造RL相邻转移，没有把无效图像补成有效。

对这63个原窗口检查密集30Hz轨迹，无任何一个被5Hz抽帧独自漏掉了原条件下的抬升；因此本组首要问题是边界而非抽帧频率。改用闭爪行高度作对照可让10个出现合格高度，但这是诊断，不批准改变参考点。正式修订应区分“专家介入位置”和“抓取抬升参考位置”，不能用整个未来片段最低点制造成功条件。

**聚合也过严，但不能直接放宽成成功。** 当前任意一次明确持物加任意一次明确空手就整段复核；空手则要求所有合格帧都判空。仅允许unknown帧存在、保留连续空手条件的敏感性对照，会把18个转为候选空手；只要有连续持物就忽略混合，则会把21个转为候选持物。这两个数字都不是验收改善。定向检查4个混合例：E01-L003可见蓝色积木后消失，E05-R002可见红色积木后落入框，符合正常放下的可能；E04-R019/E04-R022的所谓持物帧指间未见积木，反而揭示背景/模糊误报。不能把21个全部奖1，也不能把这4例当独立精度评估。原图对照见同目录`mixed-examples-1.jpg/2.jpg`及`visual-spot-notes.json`。

**视觉参考库小且偏。** 20张参考只有7张空手，其中6张来自E04。为避免泄漏，E04查询整集排除后只剩E01的一张空手参考；E04共40候选中33个待复核，且没有聚合空手候选。此为明确的参考覆盖缺陷，不能靠重新允许同集参考“提高准确率”。全量1019帧中187帧为ROI/CLS冲突或低差值，19帧几何失败、1帧裁剪越界；不能把165个候选都归咎于SAM3。ROI与CLS来自同一个DINO骨干，不是两个独立验证器；整图分支还可能被背景主导。去掉CLS的单独对照只使明确候选从108变114，也说明仅换聚合分支不足以修好链路。

数据修订顺序建议为：①保留真实动作尝试身份，缺图只跳过证据，不在短暂观测缺行时无条件终止；真实epoch变化、反馈失效及任务结束仍切断；②加入抓取阶段与容器外条件，排除投放/运输中的闭爪调整，273个闭爪候选不称273次真实抓取；③在放置开始前完成抓取核验，区分持物后正常松开、意外掉落、始终空手；④补跨集、跨臂、跨背景的持物/空手参考，用冻结规则的新样本验收误报。自动跟踪仍关闭。正式候选v2保持不变，用户已有审核可按旧ID追溯，未来重建必须带旧新映射。

## VLA RL 对比与动作修正提案

以下比较直接依据原论文，框架、动作表示与RL算法分别讨论。论文报告的真机交互分钟数不视为本项目训练耗时，各方法任务、奖励与人为帮助不同，不用跨论文成功率排行。

| 方法 | 优化对象及机制 | 对当前目标的启示与代价 |
|---|---|---|
| [PARTS](https://arxiv.org/html/2609.21788v2) | 冻结VLA，小残差动作块TD3+BC；自动selector/verifier/reset与成功重加权重训。 | 局部练习与自动核验适合当前抓取；通用框架可选末端平移等维度，附录乐高配置却仅选开度，不能照抄它的动作mask。论文不含把全部经验蒸馏回VLA的完整闭环。 |
| [PLD](https://arxiv.org/html/2511.00091v1) | 冻结VLA、残差SAC，Cal-QL初始化；base probing后专家接管，混合轨迹SFT回VLA。 | 与“经验长期留在模型”最贴近；成功基础rollout作初始离线池，不代表无需在线尝试。原方法单步残差，结合当前RTC应另验证动作块适配。 |
| [RLT](https://arxiv.org/html/2604.23073v2) | 先训练压缩RL token，再冻结VLA/token；小actor-critic修正整动作块，TD3式价值学习、参考L2约束和reference dropout。 | 动作修正不局限高度/夹爪。动作纠正数据可选人工，但论文的阶段切换和奖励仍依赖人；自动化这些部分是额外工程。token还需预训练，不是直接把现有Pi接上即可。 |
| [EXPO-FT](https://arxiv.org/html/2605.25477v1) | 小edit策略优化Q/熵；在基础与编辑动作块中择优；VLA用原生flow-matching继续学回放。 | 更直接地联合动作编辑与VLA吸收，支持广泛动作维度；多候选推理成本和critic对未试动作的误估需验收。此项目已有独立并行路线，本分工不切换实现。 |
| [Real-Time EXPO-FT](https://arxiv.org/html/2609.18207v1) | 延迟感知的chunk价值/编辑，训练时RTC，保持已承诺prefix；自动reward，本论文实验无人工干预。 | 对快速YAM很相关：修正只能作用尚未承诺的后缀。公开实验64个候选/次推理是其具体配置，不能直接当Thor可承受成本。 |
| [DSRL](https://arxiv.org/html/2506.15799v2) | 冻结动作生成器，用SAC等优化初始噪声；DSRL-NA另用动作critic帮助噪声学习。 | 改整条生成轨迹且利用VLA先验，但受限于底座可被噪声引导出的行为；若所有模式都下降不足，不保证能靠换噪声补出。原录制若无噪声身份，直接噪声空间离线学习还有数据缺口。 |
| [VLA-Precision / ACoB](https://arxiv.org/html/2609.04355) | 冻结多模态prefix，在线训练action expert的LoRA；全局TD、人工纠正相对原提议的配对排序、参考正则。 | 直接改动作生成能力；有效人类纠正是配对监督来源，原提议没有真实下一状态不能混作执行动作TD。我们快机器人+慢键盘不宜把这部分当主数据来源。 |
| [LWD / DIVL + QAM](https://arxiv.org/html/2605.00416v2) | 标量Q加分布式V，分位数bootstrap与熵自适应乐观程度；QAM优化flow动作生成器。 | 适合异构replay与长期多任务在线学习，不是只换一个critic就能完整复现。14集的主要瓶颈先是attempt/奖励与非零修正覆盖，不能靠分布式价值补出。 |
| [RECAP / π*0.6](https://arxiv.org/html/2511.14759v1) | 价值估计生成动作优势，所有好坏数据参与优势条件策略训练；推理正优势条件，可用CFG。 | 是更充分利用好坏经验反哺VLA的后续方向。论文也用阈值与β=1正条件采样，不能概括成“大CFG权重自动学好”；有模型与训练合同改动。 |
| [ConRFT](https://arxiv.org/html/2502.05450) | 冻结视觉/Transformer、换为consistency动作头；Cal-ConRFT离线BC+Q初始化，再HIL在线学习。 | 整动作优化可行，但换头与人为纠正流程使其不是保留现有Pi0.5原生flow头的最小适配。 |

[HIL-SERL](https://hil-serl.github.io/)是上述实时专家学习的重要参考：小视觉策略、稀疏reward分类器、demo buffer加在线介入；它本身不是VLA微调算法。用户视频中的“SURREAL”名称未找到与这段描述对应的PI一手资料，因此不将其当独立已核实算法。

**对DIVL需要精确表述。** 它的Q仍是标量，V表示当前状态下replay动作所获Q值的分布，再取分位数做bootstrap；它不是自动给每种真实结果分类的奖励器。0.43可以是正确的期望值，不能仅因单次结果只有0/1就叫“谎言”；IQL也采用非对称expectile，而不是普通均值。DIVL对混合经验的表达有价值，但不能辨认错误奖励、恢复被截断的轨迹，或知道没执行过的修正实际会怎样。

**本分工的研究建议：PARTS式局部练习与核验，扩展为整臂动作块修正，再走PLD式经验蒸馏。** 先保留已微调Pi，输入多视角特征、关节/夹爪状态、Pi参考动作块及必要短历史，小专家输出平滑连续的残差。当前参与抓取的臂开放6关节与夹爪共7维；双臂14D输出合同保留，另一臂默认Pi，双臂同时抓取/协调的开放另设受控对照。也可另比Cartesian位置+姿态+夹爪，但需经验证的坐标/IK适配，不能把Cartesian毫米直接加到关节动作。

专家窗口从末段接近/对准开始，覆盖下降、闭爪、抬升；这样学到的不仅是动作幅度，还能通过整段曲线调整朝向、横向对齐和闭合时机。只在空抓后才介入，无法修正之前已错过的接近动作。动作维度与残差幅度是两件事：开放7维仍可有界、限连续性、限工作空间；RTC已承诺前缀必须保持。探索应为平滑动作块扰动，不给每个关节每帧独立抖动。

学习器建议先以**chunk-level TD3+参考/成功BC约束**作为可比较基线，另以残差SAC作算法对照；前者便于沿用PARTS检查机制，后者对应PLD的专家学习。二者不预判谁一定赢；动作、数据、奖励与评估必须一致后比较。参考正则/reference dropout、成功重加权可单独消融，不能一次全开后把收益归给某一技巧。此为研究建议，没有写新训练配方、训练命令或改动作mask。

奖励首先回答“这段动作是否真正抓起并在核验窗口持住”，确认1、清晰空抓0、不清楚null；通过TD把结果归因到之前接近/下降/闭合动作。下降更深只是可能解法，不能将“越低奖励越高”当目标。只奖抓住不能直接教正确颜色框，因此整轮正确分拣比例、分错与掉落继续保留评估，未来若扩到运输/放置RL需补对应结果监督。

当前14集都是Pi动作、行为残差为0，可做行为价值/离线尺度初始化与示范参考，不能证明对非零残差的Q估计可靠，也不能把未试的修正当专家数据。动作修正收益需要真实有界尝试再评估；人工接管是可选辅助而非训练前提。积累确实有效的纠正轨迹后，先以PLD式原生SFT蒸馏验证主模型能否吸收，再考虑RECAP式优势条件利用失败数据。当前仍停留在数据修订与技术路线讨论，无训练、部署或自动跟踪。
