# 首轮 PLD 行为价值初始化实验

## 问题与范围

冻结现有200000步Pi0.5，用已审核的14集自主录像初始化局部抓取评估器，为后续有界残差SAC准备。左右臂共享网络并提供活动臂条件。当前录像中没有执行过非零残差，因此本轮不训练actor、不声称修正动作有效、不部署。代码为新独立包 `packages/pld-rl/`，未复用历史learner实现。

依据：[PLD §3.1](https://arxiv.org/html/2511.00091v1)、[Cal-QL Eq5.1](https://arxiv.org/html/2303.05479#S5)。本轮使用记录的下一动作作行为TD回传，无SAC actor/熵更新；Cal-QL为有限局部提案的期望形式。原文ResNet10替换为官方预训练ResNet18，原始执行tick的单步转移不等于后续RTC短块控制器。以上均为项目适配，不能称逐项完整复现。

## 数据如何进入训练

```text
不可变原始录像/HDF5 + 分类/审核/抬升资格侧车
    ↓ 原始tick/epoch/时间、video_indices对齐；不压紧缺口
311次尝试 → 31,077条 (o, a, r, o_next, terminal, dt)
    ↓ 当前三视角RGB → 冻结官方ResNet18 → 3×512维缓存
    ↓ 当前/过去状态、过去动作、当前Pi参考、活动臂与队列标量
双Q评估实际执行动作；中间r=0，核验终点仅一次r=1或0
    ↓ 行为TD回传 + MC校准的Cal-QL惩罚
固定E01诊断；保存原始曲线、逐次预测、全部检查点
```

327条资格通过标签保留，15条缺抬升证据不当负例；16条有标签但缺精确终点合法观察转移，保留原件、不强接。训练E02–14共299次（117成功/182失败），验证E01共12次（10成功/2失败）。有31,077条转移，但只有311次结果，不能把帧数当独立实验数。

在各尝试核验终点的转移发1/0，中间0，终点bootstrap为0。实际dt折扣为 `0.99^dt`；MC校准仅沿物理连续的终点后缀定义，成功片段早期的MC接近1不是早期即时奖励1。整轮C/N保留为基线评估，不在本轮重复加到局部奖励。关节目标相对当前状态，夹爪absolute；所有单位保留原始语义。实际base_target与下发动作逐行一致，行为残差0。图像与输入均只取当前/过去，标签与未来核验画面不作为输入。

## 指标与解释边界

训练指标为TD loss、Cal-QL惩罚、Q均值/分歧、梯度范数、吞吐与显存；验证为行为TD误差、MC回报RMSE/偏差、接近阶段入口AUC及分臂计数/Q。AUC只用固定入口，避免混合闭爪前后画面造成阶段捷径。E01只有两次失败且左臂无失败；不能用该验证声称稳健检测准确率，更不能称真机成功率。E01也参与过视觉调试，不是感知系统未见测试。

看板复用VLA现有页面，配置 `configs/dashboards/pld-offline14-20261012.json`，本地端口8766；原VLA端口8765保持原配置。只读同步，原始指标完整保留；曲线下降不等于机械臂成功率上升。

## 首轮实际结果与校准对照

2311已完成：特征缓存345.8秒，四组各5000更新耗时15.4–22.5秒，峰值训练显存约0.42–0.49GiB/卡。固定E01入口MC RMSE最终为A 9.654、B 6.512、C 18.531、D 1.162；前三组出现明显Q高估，D的TD误差低但未将已知成功回报传到前段。完整数值归[results-v1.json](results-v1.json)，所有周期checkpoint、预测与曲线留服务器。不能把低TD loss、较高AUC或正常完成5000步当作价值模型验收。

推断当前局部提案保守项与固定行为TD的适配失衡，尚不能归因于14集数量。原文Cal-QL/PLD包括完整策略学习及后续在线经验，本轮只训练行为评估器；这个失败首先属于项目适配诊断，不能据此否定原文算法。首轮权重不推荐交给动作优化器。

新增2312校准诊断（新run目录v2，不覆盖v1）：四组均用成功/失败混合、同一replay/特征/split及5000更新预算。E为混合TD-only；F为TD＋MC回报锚点（系数1）；G/H为F加低权重Cal-QL（0.01，seed0/1）。MC锚点为 `mean((Q_behavior - recorded_MC_return)^2)`，只在有物理连续真实结局的样本定义，标签仍不作输入。它是本项目的行为价值初始化扩展，奖励定义/位置不变，不称原文完整Cal-QL。F/G/H的对比检验回报传播和低权重保守项，仍不训练actor或生成非零动作。

2312也已完成，全部5000步，每组16.6–26.6秒；固定特征无需重算。最终结果如下，完整数值归[results-v2.json](results-v2.json)：

| 组 | 入口MC RMSE | 全体入口AUC | 右臂入口AUC |
|---|---:|---:|---:|
| E 混合TD | 1.2424 | 0.35 | 0.5 |
| F MC＋TD | 0.6367 | 0.40 | 0.0 |
| G MC＋TD＋低权重Cal-QL seed0 | 0.6341 | 0.40 | 0.0 |
| H 同G seed1 | 0.6284 | 0.65 | 0.4 |

**数值稳定不是价值验收。** 用混合训练集入口平均回报作常数预测，E01的RMSE为0.5560；恒预测1为0.4097。F/G/H都未胜过这两个简单基线。第一轮成功组的训练均值常数也达到0.3932，因此早期best checkpoint约0.39并没有证明学到比常数更好的信息。左臂验证全成功不能算AUC；右臂仅5成功/2失败，整体AUC可受臂间差异影响，必须同时报告同臂指标。[基线分析v1](baselines-v1.json)、[v2](baselines-v2.json)及可重算入口 `scripts/pld_rl/analyze_runs.py`留存。E01反复用于诊断/调参，仍只能作为开发验证，不能升级成最终独立测试。当前不推荐任何一组用于动作优化，也没有专家成功率提升结论。
