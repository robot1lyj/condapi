## 训练与选择

同一冻结replay上完成TD3+BC、IQL、SAC、成功BC控制各2个seed，基础网络256宽×3层；另做64宽×2层的TD3+BC/IQL各2个seed，以及同小网络保留Pi计划/状态、压低原ImageNet视觉输入的4组消融。后者视觉除数1e6是明确的输入消融，不冒充经验RMS。总共16组，每组3000步critic、200次父actor行为中心坐标对齐、500次actor更新，batch256、lr3e-4、MC初始化1000步、critic预热2000步。BC控制的actor目标不含RL项；它不是第四种RL算法。

Pi与编码器冻结，所有优化器实际在Thor隔离容器执行。16组优化器循环合计约501秒；这个时间不含备份、判奖和工程验收。全部配方、优化器/RNG、96个检查点、原始曲线和逐次预测保留，有限值/导出一致/记录状态可行性/保存验证复现均通过。

**真正未解决的问题是价值泛化。** 基础IQL seed0训练入口AUC=1，开发验证入口AUC=0.43、回报RMSE=0.642，右臂入口AUC=0.114。小网络与输入消融也未解决右臂问题。开发验证仅第一集20次尝试且被多次诊断使用，不能充当独立测试集；SAC为含熵soft Q，不能按MC误差与其他算法直接排名。

选基础IQL seed0/3000用于后续受控测试，是因为离线actor学习仍约束于实际执行动作、记录上下文的确定性输出和几何审计通过，未选择依赖更强离线Q外推的SAC。不是取20次开发验证得分最高的seed，也不是认为该critic已能可靠评价新动作。测试后才决定是否保留这个候选。
