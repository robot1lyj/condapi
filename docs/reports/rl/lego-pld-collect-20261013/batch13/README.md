## 训练质量判定：尚未证实收敛，末版actor不直接部署

本轮训练数值稳定且有学习信号，但不能以1000步完成宣布收敛。训练终点RMSE0.085、验证0.303，存在明显泛化差距；验证集仅第一集42窗/11正例，且结果主要为模型伪标签，不能证明奖励器准确率。固定0.5预测RMSE0.5，用训练集成功比例作常数预测的验证RMSE0.4485；当前critic确实优于常数基线。

保存检查点的验证终点RMSE：250步0.3993、500步0.3147、750步0.2919、1000步0.3029；全日志740步最低0.2849。终点指标在后段停滞/回弹。非终点Bellman验证loss从120步最低0.0371升至1000步0.0765，提示价值传播泛化/移动目标/策略外推风险，不能单凭这一条判定确定过拟合。

新的[完整检查点质量审计](sac-r01-checkpoint-audit-v2.json)逐份加载4个完整learner及actor包，没有运行优化器或机器人。训练状态上有可编辑余量的2701个决策块，采集动作归一化偏移RMS0.19249；各检查点的确定性actor偏移RMS分别0.13045、0.23075、0.28436、0.39724，末版约为行为数据2.06倍。各维动作落在本split行为动作1%–99%分位区间之外的标量分量比例，训练分别0%、6.62%、14.19%、30.34%，验证分别0%、7.46%、13.43%、28.51%。这是各维边际覆盖诊断，既不代表碰撞/物理越限率，也不能证明多维状态动作已在分布内；但说明末版更多依赖critic对未充分覆盖动作的估值。确定性与随机采样策略统计分开，不能用训练日志随机RMS0.527替代确定性RMS0.397。

训练终点奖励AUC1.0、验证0.9589仅表示对当前自动/人工标签的终点区分；成功画面就在终点输入中，不能由此推出闭爪前的动作选择正确。Actor loss下降也是critic自评，不能当独立策略评估。1000×batch256/3126约82次采样复用量，步数再加大会持续重用同一小批经验，单纯延长不等于新证据。

判断：critic终点识别有学习信号，尚未证明入口动作估值有效，actor仍是待验候选，未达到成熟部署验收。残差变大是外推风险信号，不是单独证明策略变差。保留500/750/1000等所有版本，不按最低critic误差断言某actor真机最佳；停止本批无约束加步数。新[论文与官方实现对照](method-comparison.md)确认：当前固定Replay裸SAC未实现PLD的Cal-QL初始化/成功先验混合，也未实现PARTS的成功BC/重加权。入口验证AUC仅0.610，终点0.959；因此优先补价值初始化，并以独立PARTS-TD3BC为对照，不能只凭终点分数选actor。更充分训练critic可能有价值；限制的是无新证据地继续无约束训练actor。实际减少空抓仍需新策略真机经验。当前没有启动这些新配方或部署学习actor。
