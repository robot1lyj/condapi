# 第二轮：先检验价值与动作约束，再小批真机对照

用户授权自行选择后续算法。决定先用已有13集完成固定数据对照，不部署R01末版，不先索取另一批20集。当前数据足够暴露实现与离线学习问题，无法单凭离线Q证明新动作更好；之后仍需要新策略的真实执行结果。

## 抓取窗口与RTC

原467次完整抓取、3417个区间含2950个可修正区间及467个强制等待尾段。2927/2950个修正首次生效不早于下一次观测，首次生效延迟11个tick，约0.367秒。尾段中位0.366秒。原观测包含已承诺RTC前缀，延迟本身不等于转移错误；但尾段没有可选动作，终点识别容易掩盖早期动作估值质量。

新学习视图`learning-replay-r02-v1`仅把每次最后一个可修正动作与之后强制等待合并，最终结果画面与奖励标签不变。若合并原转移i到k，采用：

`R = r_i + d_i*r_(i+1) + …`；`D = d_i*…*d_k`；`next_state = s_(k+1)`。

不丢时间、不提前视觉标签、不跨抓取、不重复发奖励。逐次比较合并前后入口折扣回报相等；保留原转移索引、原Replay SHA、候选和原始录像。新视图2950条，训练2701、首集验证249；抓取仍425训练/42验证。失败0、成功1仍为任务终点定义，合并后的最后动作即时奖励会因等待折扣略低于1。`attempt_outcome`另存原始1/0，用于整段成功采样和BC，不能按`reward==1`挑BC动作。

每组seed0/1。batch256、lr3e-4、双Q宽256/深3/LN、FP32、每500保存/每50记录、固定ResNet18/Pi；每组3000 critic/500 actor更新。固定成功尝试50%＋所有尝试50%采样，各池先均匀取尝试再取决策。成功池是实际带修正采集，不能冒充PLD原文的纯基础策略成功示范池。首集不参与训练、归一化或成功池；它曾被检查，不称盲测。没有增加真实环境样本。

CalQL并非把MC回归改名：TD损失外另有分布外提案保守项，其策略提案Q下界由记录MC回报校准。使用每状态10个当前策略提案与10个均匀潜动作，密度校正均在`u∈[-1,1]^7`；Q输入仍是按状态可执行余量映射后的实际归一化残差。CQL权重0.1；不把物理限幅投影后的奇异分布当作有完整密度。SAC actor保留熵项，Bellman目标关闭熵。MC初始化是本项目对完整抓取片段的对照变体，不是PLD原文等价步骤。

PARTS组使用TD3目标动作噪声0.2/裁剪0.5，成功BC覆盖成功抓取的每个可控决策，失败零锚权重0.1；Q项按平均绝对Q归一化、alpha=0.1，优先约束小数据外推。保留运行时兼容的Gaussian网络，TD3只优化确定性均值，采集标准差维持bootstrap；不同于原文直接裁剪动作噪声。原PARTS乐高主要改夹爪，本实验是七维整段抓取扩展，不能称逐项复现。

## 看什么，怎样决定下一步

固定记录回报RMSE与成败AUC分别报告入口、全段、最后一次可修正决策及左右臂；同时报告动作RMS、训练动作各维1%–99%范围外比例、双Q分歧、Bellman误差。验证不消耗训练随机数。记录回报是旧行为结果，不是新策略真实价值的监督真值；成功重采样也改变了训练分布，Q不直接显示为成功概率。

选择候选时先排除数值异常、明显动作外推、左右单边失效以及保存/导出不一致，再综合多seed与不同训练阶段，不按最低终点loss挑“机器人最优”。学习包在Thor独立训练容器生成，生产推理保持停止、现行actor未替换、原修正范围与客户端协议不变。

若候选稳定，下一步同初态分布交替采少量纯Pi与确定性候选（先每组2集），核查执行链、是否误介入、空抓率、抓起持住率和耗时，整轮C/N仅观察是否退步。确认执行和方向后，再采约20集有界collect用于下一次更新。两集仅用于工程验收，不能据此宣称统计显著。若所有方案入口价值或动作选择都无改善，优先审计动作是否有足够作用时间/幅度、视觉输入是否被计划特征淹没、成功失败在同状态附近是否有可辨别修正，再决定定向采集；不重复对同批数据无限加步数。

## 针对输入表示的追加对照

第一批六组已完成，CalQL两个seed入口记录回报RMSE分别3.426/1.839，MC-CalQL为1.251/1.121，均没有得到可信的回报尺度；PARTS为0.502/0.498，动作RMS0.137/0.135，比R01小，但入口AUC0.581/0.572仍不能证明会选动作。因此不按“动作缩小”直接部署。

进一步CPU审计：467次均有闭爪时点和实际修正；其中451次在在线检测闭爪前已生效，提前量中位0.7秒。该闭爪时点是相对开合检测，不是接触真值，不能解释成精确触物时间。多数窗口有提前修正机会，16次没有，应在后续介入改进单独关注，当前不借此重标奖励。

五组输入训练集平均平方L2：视觉3.0、状态15.27、Pi计划6789.79、上一指令15.86、上下文/余量16.75。直接拼接后首次随机线性投影的计划贡献可能远大于图像及残差动作；这只是可检验的机制线索，不是因果证明。追加`PARTS-TD3BC-Balanced` seed0/1，与前述PARTS完全同配方和初始化，只对五组观测分别除以训练集块RMS。不删视觉、不删计划、不改RTC队列；不使用验证数据计算尺度。Q的动作输入仍为原可执行归一化残差。

变换在actor/critic内部，固定增益作为buffer保存，数据合同保持；如后续选中此组，部署必须携带支持`FeatureBalance`的新运行时，旧运行时会因未知权重键拒绝加载，不能仅替换生产actor文件。原无平衡模型使用无参数Identity，保留旧checkpoint键与旧推理数值路径。

论文和固定官方代码出处见[方法对照](method-comparison.md)。CPU回报守恒与原抓取回归、两算法GPU数值/CLI/保存导出检查已通过；追加平衡组及旧SAC回归GPU检查亦通过；全部八组已完成，尚未宣称真机改善。

## 完成结果与当前选择

八组累计24,000次critic、4,000次actor更新；更新/评估/保存循环合计450.02秒（不含环境启动、代码开发、数据处理、验收和部署）。48份checkpoint逐一验证参数有限、bundle权重完全一致、记录状态下可行域符合、保存验证指标重算一致。完整汇总见[round02-results.json](round02-results.json)，训练全过程和所有模型保留在Thor独立run目录；工作站只镜像结果，没有训练。

必须比较强基线：只用训练集左右臂成功比例（左0.507/右0.272），首集入口AUC已0.705、记录回报RMSE0.412。平衡组整体AUC0.73不能夸大为大幅突破，绝不是73%机器人成功率。平衡组左臂AUC0.857/0.878，右臂仅0.583/0.542；验证右臂仅4个正例，仍缺乏有效动作选择证据。

决定停止对同一批数据继续无止境调算法，采用`parts-td3bc-balanced-collect13-r02-s0/bundle-003000`作为**工程试跑候选**，而非宣布训练收敛或真机更优。框架仍是冻结Pi＋外挂残差专家，当前actor训练目标选择PARTS风格TD3+BC。seed0作为代表版本，保留seed1核对趋势，不宣称它是真机最优。

候选快照`75674aad5775e4864cce24664abd270e43a2a82b7e64f95811ce952979b2d286`。对2950个真实记录上下文（左1159/右1791）加载完整运行时并重放解码，前缀及非活动臂逐值不变；实际计划的最大关节修正0.014356rad、夹爪0.028209，目标FK位移中位1.99mm/P95 4.29mm/最大9.45mm。它说明当前候选是毫米级目标微调，不能据此承诺修复几厘米的下降误差。回放没有改变后续状态，不替代闭环轨迹与接触验收。
