## 实际算法

- 保留 Pi 原计划，叠加有界关节目标偏移。collect 上限仍为关节 ±0.08 rad、夹爪 ±0.05；上限不是每次实际扰动幅度。
- 新噪声每次都更新，但与上次相关：`eta = rho * eta_prev + sqrt(1-rho²) * innovation`，`rho = exp(-elapsed/0.5s)`。每次仍可反向，绝不锁定整次抓取的方向；触及几何阻断或无有效轨迹时清除噪声记忆。
- 以不可修改的 RTC 前缀为起点，第一步延续前缀末端速度，再用五次多项式渐变到新偏移。默认渐变 12 步，速度外推增益 0.25，有限尾部平滑归零；每个新请求重新规划，最长修正候选 36 步。
- 约束偏移、关节目标变化和目标二阶差分。新 Pi 参考切换边界直接约束实际目标连续性；不能把参考改变产生的残差变化误当成机械臂跳变。
- eval 不加探索噪声，保留原 actor ±0.02 rad 目标尺度，也使用新连续解码器和作用范围约束。因此不能宣称 eval 的完整物理轨迹与旧版逐点相同。

## 不持续向错误方向压下

目标相对于每次新 Pi 计划有界，不累加成无限位移。噪声短期相关、每次有新变化；actor 每次根据新观测重新计算。轨迹超出可修正空间时缩小目标，仍不合格则返回 Pi 并清空探索历史。这只是约束探索，不是已经具备接触感知或保证发现错误方向。

## 抓取范围与退出

依据 measured FK 和 Pi 预测轨迹限制介入；检测闭合后的 5 cm 抬升、重新张开、离开抓取空间后，停止新增修正。退出时只等待已经提交的 RTC 前缀，未提交的旧修正尾部被新回复覆盖；Replay 要验证该退出回复确实被接收和执行后，才能对齐奖励。

本场景采用每臂自身 FK 的 `x ≤ 0.40m`，并沿用抓取高度下界和上界加 0.12m。该 x 边界来自第二轮录像的桌面与容器位置，是现场标定，不能用于任意摆放的容器或其他任务。修正后的整段 FK 也必须通过同样检查。最近录像的两段正式放置没有附加残差；离开容器时提前触发的问题由当前姿态与未来姿态双重检查收紧。

## 数据合同

新 action 为归一化目标，经确定性的连续轨迹与几何投影得到实际动作。记录 `trajectory_context`、投影、相关噪声、Pi 原计划与实际目标；Replay 从原始状态和计划重建解码器，并核验实际执行。旧三角脉冲合同和新合同不能直接混为同一种动作映射训练；后续训练需显式适配新解码器。
