# Actor-2 Closing-Collect r05：独立增加闭爪探索

20w Pi＋已学习Actor-2的collect候选已接回`ws://192.168.250.1:8000`，MAXN、healthy。本轮没有训练“更强的闭爪Actor-3”：actor文件仍为`bffec6f3…`；eval逐值保持旧Actor-2，只有collect预算与探索分布改变。R04的IQL/SAC/BC候选另存，不自动替换当前专家。

## 改了什么

| 项目 | 父Actor-2 collect | 本候选collect | eval |
|---|---:|---:|---:|
| 关节残差预算 | ±0.08 rad | ±0.08 rad | 原Actor-2 |
| 夹爪额外闭合预算 | 0.05 | 0.20 | 原Actor-2，±0.05 |
| 夹爪额外张开预算 | 0.05 | 0.05 | 原Actor-2 |
| 夹爪残差每tick增量上限 | 0.02 | 0.04 | 原Actor-2 |
| 夹爪latent噪声标准差 | 0.2 | 0.7 | 0，无探索 |

夹爪数值为归一化开度的**额外目标差**，不是rad、毫米或夹持力。负号表示比Pi更闭合；动作仍加在本次Pi计划上，不累计成持续向内的漂移。使用原相关噪声tau0.5秒，可反向；原速度/二阶差分/限位/几何投影继续约束实际输出。根合同增加`positive_radius/negative_radius`，坐标radius为夹爪0.20，张开方向实际支持最多0.05，故归一化正向scale最多0.25。父actor保留原0.05坐标，使用自己的规划上下文/可行边界；当新承诺前缀超出父坐标桥接能力，父上下文可以折叠为0，不能拿新边界伪装父actor输入。

不改在线触发规则，不延长到运输/放置；原有5cm抬升/重新张开退出、RTC前缀10、抓取空间和两臂仲裁保留。`short_closing_min_steps=5`补丁仍未启用；不足9个可编辑tick的请求继续退回Pi。因此本轮加强的是**已有更早长窗口里的闭合探索**，不是解决所有短窗口漏控。抓起持住1/有证据失败0的奖励方法不改，C/N仍仅评估。

## 实际余量检查

同原10集1404个允许残差的记录上下文，863个可修正、537个短窗口不足、4个桥接超约束；每个可修正上下文固定16份相同随机数，父与候选各13,808个解码轨迹。它们是独立记录状态的几何/命令抽样，不是新的机器人交互或完整时序rollout。

| 实际解码量 | 父collect | 新collect |
|---|---:|---:|
| 额外闭合P95 | 0.0219 | 0.1418 |
| 首10个可编辑tick内额外闭合P95 | 0.0211 | 0.1291 |
| 额外闭合≥0.05的候选占比 | 0 | 23.56% |
| 额外闭合≥0.10的候选占比 | 0 | 11.28% |
| 额外闭合≥0.15的候选占比 | 0 | 3.91% |
| 额外张开最大值 | 0.0401 | 0.0492 |

这说明扩大后的闭合探索经过平滑/约束仍有实际余量，不代表成功率提高。相同抽样下关节FK分位值与几何投影计数完全一致；前10个可编辑tick末端偏移P95为35.94mm。双臂均有足够的闭合方向支持。每条样本检查方向预算、物理步长/二阶差分、前缀、非活动臂、退出后的尾段；全部通过。原始统计见[父版本](parent-bundle-authority-v2.json)、[新候选](bundle-authority-v2.json)。
