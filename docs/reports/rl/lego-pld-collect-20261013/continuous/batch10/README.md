## Actor现场指标

固定N=10，先报告C/N与完整完成率。完整完成的轮次比较抓取尝试数A与耗时；可以附加效率分`min(1,10/A)`，未完成记0，避免提前停录的轮次因次数少占优。`C/A`只描述整任务完成效率，不叫局部抓取成功率。
