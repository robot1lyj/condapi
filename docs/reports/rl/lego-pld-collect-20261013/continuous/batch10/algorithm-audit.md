# 当前算法适用性与下一轮比较

2026-10-14最初在用户占用Thor期间仅做CPU数据/规划检查；随后用户明确释放Thor并授权暂停推理进行实验。R04已完成同连续轨迹合同TD3BC/SAC/IQL/BC各两seed与48个checkpoint审计，基线重复性通过，见[R04结果](round04/README.md)。下方“33组”与“下一轮”保留为该审计形成时的历史清单和设计；最新结果、服务状态分别以R04报告与08为准。下一批Pi已由用户固定20w，24w服务保留。

## TD3＋BC到底在学习什么

PLD指冻结VLA＋残差专家＋后续蒸馏的框架，[原文算法1](https://arxiv.org/html/2511.00091v1)用SAC更新残差策略，并不要求必须使用TD3＋BC。[TD3＋BC官方代码](https://github.com/sfujim/TD3_BC/blob/main/TD3_BC.py)在策略目标中组合Q最大化与记录动作MSE；当前实现另作成功筛选与失败零修正锚定，因此是项目变体。

当前BC目标为成功尝试中每个可控决策的7D可行归一化残差target（执行轨迹/几何投影前），不是积木的绝对姿势或完整演示轨迹。输入包含1536维三视角冻结ResNet18特征、14D状态、700维Pi动作计划、上一实际命令、活动臂、延迟/时长及窗口/可行余量。网络应学习条件映射：相同偏差时怎样修，积木和姿态不必相同。

但当前目标存在三个风险：

1. 一次尝试成功，不能证明里面每个随机修正都有帮助；successful BC会同时拟合偶然探索、Pi本来就能完成的段落。
2. 若视觉/状态分不清两种需要相反修正的情况，确定性MSE会倾向折中；跨全部状态的平均残差接近0本身不是这个问题的证据，需要相似条件下的动作对照。
3. 失败状态被锚到0是工程保守项，不是RL定律；它可能在最需要纠错时压制修正。已做NoAnchor对照，但它动作更偏离数据，不能据更大幅度就判更好。

因此TD3＋BC保留为基线，不能凭名字保证满足需求。当前critic尚无足够可靠的动作排序证据，不能把“整段成功”自动称为残差正优势。

## 曲线的真实问题

TD目标随target网络/策略变化，MC初始化→TD、critic预热→actor更新都有目标切换；actor loss含负Q、BC与锚定项，不要求向0下降。不同算法的总loss尺度不能直接排名，也不能只因不平滑就判训练失败。

但当前有可量化弱点：TD3BC入口验证记录回报RMSE0.572/0.578，训练均值常数0.455、按左右臂均值常数0.450；其全段验证AUC0.505/0.521。BC对照入口AUC0.80/0.783高于TD3BC的0.70/0.65；仍只有17次开发验证，不能据此排名真实策略。自举策略Q与记录行为MC并非同一真值，基线是诊断，不能单凭MC误差否定策略；也不能据自评Q变高宣称改进。[可复算基线](behavior-return-baselines.json)。

下一轮保留入口/全段/同臂价值诊断、常数基线、动作范围外比例、真实生效tick与闭合时可控时间；实际主指标仍为持住/空抓、完成率、完整完成时抓取次数/耗时，重复初态分布对照。

## 短闭合候选与它的限制

新增`trajectory.short_closing_min_steps=5`，只在明确闭合且剩5–8个可编辑tick时允许新的闭合目标：关节新目标和张开方向支持为0，已有承诺关节桥接继续按原约束平滑恢复；不改RTC前缀、不延长到5cm抬升/重新张开之后，不放松速度/二阶差分/空间约束。默认没有此字段，旧路径保持。合成合法场景及基线跳变拒绝等37项CPU回归通过，没有运行训练循环。

第11集182个记录上下文重建通过，浮点最大误差1.78e-15；正常长窗口路径不变。49个短窗口请求中仅新增5个可闭合请求（5个窗口），最大可额外闭合0.03213；仍有44个不足以使用这个候选。因此这只是局部补丁，未解决主要缺口，未生成上线bundle、未GPU验收或部署。[逐请求检查](short-closing-authority-v1.json)。合成最大闭合是控制余量，不是新actor预测或成功结果。

更关键的优化方向是让闭合修正在更早、仍可编辑时发生，按Pi实际闭合缺口设计夹爪独立的探索范围；不能指望在已承诺前缀内补救，不能把所有姿态都强制闭到0.02。关节修正与夹爪闭合需分别核对可用时长/幅度，仍禁止专家进入放置。新动作合同需要独立身份与验收，旧数据只通过显式坐标转换复用。

## 下一轮安排

先完成动作窗口/闭合控制余量的离线审计和候选代码，不先让用户再录同样的20集。Thor可用且用户安排现场暂停后，才做GPU/协议验收、切换新collect；新范围需要真实结果学习，届时再给出小批采集要求。

新合同经验形成后，固定同一奖励、split、编码器、动作解码器与训练预算比较：TD3BC基线、残差SAC、IQL，再加BC控制。IQL需要把既有核心移植到当前可行动作/连续轨迹接口，不照搬旧零修正合同；SAC是对PLD框架原本学习器的重新公平检验。成功BC权重、失败零锚定属于单独消融，不能每组连网络/奖励都一起换。优势加权方法可后续参考[AWAC](https://awacrl.github.io/)，但在critic不可信时优势权重同样会错，不作为即插即用的解决方案。

如果同条件RL仍不超过BC，再检查冻结视觉是否分辨指间细节、是否需腕部局部特征或时序输入；无需把换大模型当作第一步。目前不宣称候选收敛，也没有新增训练任务或资源请求。
