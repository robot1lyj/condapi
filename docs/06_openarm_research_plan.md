# 06 · 历史 OpenArm 研究归档

本文件仅保留编号化文档的历史占位。旧 OpenArm、KAI0、Evo-RL、AWBC 和 HIL 方案不属于当前项目默认路线，相关代码已清理；不要把其中的动作维度、单位、数据路径或实验结论套用到 YAM。

历史原因与清理结果只记录在 `docs/07_change_log.md`；若未来重新引入 OpenArm/KAI0 研究，应以独立的新任务和新数据合同恢复，不在本文件复活旧默认路径。
