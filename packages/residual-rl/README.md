# YAM 整轮残差 RL：数据准备与学习器首版

算法依据是 [PLD](https://arxiv.org/abs/2511.00091)、[Cal-QL](https://arxiv.org/abs/2303.05479) 和 SAC。没有复用仓库旧 PARTS/RLT 的算法实现。Pi 继续使用原生 OpenPI；本包不训练 Pi、不接触机械臂控制。

当前实现包含：物理 14D action critic、零均值残差 actor、Cal-QL 风格的 critic-only 离线初始化、后续 SAC 更新、按实际秒数折扣、版本合同和完整续训状态。离线阶段不更新 actor，也没有 BC 预热。校准项采用论文的 `max(Q, MC return)`，加入保守项；不是把所有 Q 直接拟合成成功标签。仅用当前状态的策略候选和均匀候选，是相对上游实现的简化；固定熵系数。属于项目适配，未声称逐行复现 Cal-QL/PLD。

**当前不能直接接到生产推理。** 学习器代码仅静态审核，未在获准 GPU 上完成数值验证。历史 30Hz 数据适用于单步物理 action critic 的初始化候选，不是执行过的 H50 残差决策。训练需要真实三视角冻结视觉特征、同版本基础动作缓存、审核过的关节/夹爪范围和残差幅度。不能用随机特征、零填充基础动作或动作数据的极值冒充这些合同。颜色分拣不能只用关节状态训练。

上线还需明确短执行段的决策频率及 RTC 队列状态、动作来源和约束映射。已承诺前缀不允许修改；下一请求带回实际最终动作。未完成这项接口验收前，不导出或加载生产 actor。`bounded_target` 仅是纯数组协议函数，不是现有客户端的替代实现。

## 数据与奖励

- `scripts/residual_rl/audit_hil.py`：核对原始 SHA256、逐帧解码视频、审计 14D 数值与来源、保持真实时间，剔除跨无效观测/缺 tick/epoch 切换的 transition，输出独立 npz 和 sidecar。最后一个 observation 作为终点；没有下一观测的最后一条动作不伪造 transition。
- 原生 YAM 转换器由外部只读项目调用，保留完整的自动、人工、等待轨迹；审核输出与原始 HDF5 对齐。原始数据不改写。
- 整轮进度奖励为 `newly_correct / initial_remaining`。只在终点发一次。每条单独标注，失败及部分成功保留；不需要每次抓放按键。不把人工接管当奖励。
- HIL 完成轨迹的 `R=1` 来自操作者约定，必须保留 `assisted`。它不是当前模型无人帮助的成功率，更不说明每条动作都好。发生人工救场之前的 Monte Carlo 回报不作为自主回报校准证据。
- 原始全集备份、LeRobot 数据、可训练 replay 是三个层次；清洗后的 npz 尚无视觉和同版基线缓存，`training_ready=false`。
- episode 整体划分 holdout，不按帧随机切分。HIL、无人 rollout、旧示范分别存池。按 episode 抽样避免慢速人工轨迹凭帧数占据大部分 batch；具体池权重留待实验配方审核。

优先采集固定检查点的 15–20 条无人 rollout，不筛除失败。它们是初始样本，不是保证有效的样本量；需后续残差探索和部署迭代。旧成功示范是可选补充，当前不优先抽取/混入。

## 执行边界

工作站只允许静态/纯数组/数据检查，禁止执行本模块的训练或训练 smoke。服务器 GPU 资源交接后，先做数值、损失/梯度、checkpoint 恢复及零残差验收；通过后才开始确定配方的初始化实验。当前没有生成/提交训练作业，没有修改或停止已有 Pi 训练。SAC 的梯度更新不是现场数据采集：必须先有符合决策合同的真实经验。

参考校准/密度处理：[CORL Cal-QL implementation](https://github.com/corl-team/CORL/blob/main/algorithms/finetune/cal_ql.py)。本实现独立编写，未复制上游模块。
